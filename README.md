# The ChatShack

The ChatShack is a Cardiff-based, community-run peer-led mental health
support charity, founded by Scott Hartley. This repo holds the whole live
site: a React/Vite frontend and a Django backend.

- **Live site**: https://chatshack.app
- **Backend API / admin**: https://api.chatshack.app (admin login at
  `/admin/`)
- **Founder**: Scott Hartley

## What's in this repo

- `src/` — the public site itself (React 19 + Vite + TypeScript + React
  Router v7, Tailwind v4). This is what visitors see at chatshack.app.
- `backend/` — the Django + DRF backend that powers the admin, the site's
  content, every on-site form, the volunteering/events system, and
  donation checkout. See **[backend/README.md](backend/README.md)** for
  everything about how it's built, deployed, and run locally.
- `docs/` — the built output of `src/`, published via GitHub Pages (this
  folder is generated by CI, not hand-edited).

### Backend API (api.chatshack.app)

Content the frontend reads:

| Endpoint | Purpose |
|---|---|
| `GET /api/home/` | Homepage content |
| `GET /api/settings/` | Site-wide settings (contact details, social links, branding) |
| `GET /api/pages/<page>/` | Content for any other page edited in admin |
| `GET /api/events/` | Published upcoming events + shifts |

Forms the frontend submits to:

| Endpoint | Form |
|---|---|
| `POST /api/contact/` | Contact page — general enquiries |
| `POST /api/improvement-feedback/` | Contact page — website feedback & suggestions |
| `POST /api/first-contact/` | Support & Contact pages — First Contact & Initial Support |
| `POST /api/suggestions/` | Community page — "tell us what's needed" |
| `POST /api/partner-applications/` | Partners & Resources — partner application |
| `POST /api/volunteer-applications/` | Volunteer application |
| `POST /api/sleep-out-interest/` | Events page — register interest in Sleep Out to Help Out |
| `POST /api/shifts/<id>/signup/` | Volunteer shift sign-up |

Donations:

| Endpoint | Purpose |
|---|---|
| `GET /api/shop/items/` | Shop items (if any are listed) |
| `POST /api/shop/checkout/` | Stripe checkout session for a shop item |
| `POST /api/shop/donate/` | Stripe checkout session for a donation |
| `POST /api/shop/webhook/` | Stripe webhook (payment confirmation) |

Admin: `/admin/` — every submission, every page's content, events/shifts,
and site settings are all managed here. See
[backend/README.md](backend/README.md) for what's where.

## Running the frontend locally

```bash
npm install
npm run dev
```

For the backend, see [backend/README.md](backend/README.md).

## Deploying

```bash
git add -A
git commit -m "..."
git push                                        # publishes the frontend via GitHub Pages
git subtree push --prefix backend heroku main   # deploys the backend to Heroku
```

Run both from the repo root (this folder), not from inside `backend/`.
